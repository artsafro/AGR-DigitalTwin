## Следующий шаг после установки SketchUp 2026

1. Проверить путь приложения и пользовательскую папку Plugins версии 2026.
2. Установить подготовленный RBZ через Extension Manager либо скопировать его
   loader + одноимённую папку в Plugins при разрешённой файловой установке.
3. Загрузить расширение, `Extensions/Plugins → MCP Server → Start Server`.
   Автозапуск пока НЕ настроен. Не менять политику загрузки расширений молча.
4. Если новый MCP не виден в текущем чате, обновить подключение/перезапустить Codex.
5. Проверить `get_version`, `get_model_info`, `list_components`,
   `get_viewport_screenshot` на реально открытой модели.
6. Сохранить отчёт и снимок. Только после этого отмечать live_connection=true.

## Работа с исходником

- При каждом новом сеансе сверять полный `model.path`, название, версию,
  единицы и габариты. Несохранённую сцену не выдавать за исходный SKP.
- Перед анализом фиксировать исходный путь и SHA256 сохранённого SKP в задании.
  SHA256 дискового файла не описывает несохранённые изменения сцены.
- Анализ: структура групп/компонентов, world transforms, силуэт/виды,
  контуры/проёмы, определения повторяющихся этажей, материалы и UV.
- Большие массивы геометрии и извлечённые текстуры писать в файлы задания;
  в чат отдавать сводку. Сохранять связь entity/definition/material → результат.
- Перед изменениями создавать отдельную рабочую копию; исходник и approved
  версии не перезаписывать. Полное чтение SKP вне SketchUp этим мостом не обеспечено:
  требуется запущенный SketchUp и открытая модель.
- `eval_ruby` upstream включён по умолчанию; это общий доступ к Ruby API,
  а не read-only гарантия. Для запроса анализа применять только читающий код.
  Не запускать upstream `smoke_check.py` на пользовательской модели: он меняет сцену.
- Штатный screenshot upstream требует SketchUp 2026+. Просмотр снимка не заменяет QA.
