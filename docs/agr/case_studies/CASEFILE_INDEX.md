Этот указатель отделяет область пользовательской приёмки от технического QA и
публикации файлов. Последнее состояние объекта искать в его `jobs/<ID>/STATE.md`;
отсутствующий в Git `outputs/` не восстанавливается по этой записи.

Для Ground, MASHI, Facades найдены локальные исходники и определены кандидаты
на объединение по операциям; [аудит](../history/organization/TECHNICAL_MIGRATION_AUDIT.md).

[UV v006](../../technical_library/UV_V006.md). Приёмка ниже не меняется.

## Область публикации, 29.09.2026

относятся к описанному этапу, а не к текущему ревью или новому поручению.

которые в этот пакет не включены. JSON проверяется как запись, а не как
