## Задача и входы

Downloads/facades.blend, три корпуса, ID101–105. Панели кирпича1600×1200мм,
кирпич250×65мм со швом10мм; прочие панели1200×1600мм. Требуются три атласа
и ОДИН общий набор пяти бесшовных2K-карт для визуализации, не15 вариантов.
Оттенки общего набора взяты с корпуса01; оттенки отдельных атласов сохранены.
Шов панелей5мм — рабочий параметр, а не новое требование из PDF.

## Что сработало и что исправлено

Переиспользование полос атласа по ID, метрическая проекция на общие оси фасада
и сохранение старых UV дали принятую плитку. Горизонтальный стык кирпичной
панели совпал со швом ряда, а5мм при80px/m меньше пикселя: числового QA оказалось
недостаточно для проверки читаемости. В v004 стыки панелей темнее раствора;
только в атласе их растровая ширина усилена до1px (12.5мм). В отдельных2K-картах
сохранено5мм. Период панелей и размеры кирпича не изменены.
Неудачная интерпретация выдачи15PNG исправлена на3атласа+5карт.

## Воспроизведение

tools/facades_texture_pattern.py — периодический рисунок в метрах,4×4subpixel
сэмплирование; вариация кирпича тоже вычисляется в периодических координатах.
tools/build_facades_textures_v004.py запускается Blender4.4 на v003 с аргументами
после `--`: каталог v003 и новый каталог результата. UV и геометрия не меняются.
tools/package_facades_v004.py собирает окончательный ZIP и проверяет его содержимое.
Модели/PNG локально в ignored outputs, исходный blend необходим для воспроизведения.
Запуск проверок: `.venv/Scripts/python.exe -m pytest -q tests/test_facades_texture_pattern.py`.
