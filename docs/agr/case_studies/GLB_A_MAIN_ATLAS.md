## Входы и результат

3ds Max 2024, `A_Main` (12791 грань), исходная MAX-сцена и SketchUp-текстуры.
Исходные MAX/SKP сохранены. Один RGBA-атлас 2048², UDIM1001.
ID3 пользователь определил как откосы/отливы. Исходный ID15 имел 44 грани;
после перенумерации это ID5. По прямому решению пользователя они переведены
в стемалит ID13, UV сдвинуты на +0.25 U и +0.125 V.
Смена Material ID при одном атласном материале сама по себе не переносит UV.
До переноса проверено отсутствие совместных UV-вершин с другими отделками.

## Рабочая логика и перенос

[Один генератор A/B, конфигурация и команды](../../technical_library/glb_atlas/README.md)
сохраняют собственную Python-логику сборки карты из захваченных текстур и
face-UV CSV. [QA](../../technical_library/glb_atlas/QA.json) описывает свежий
строгий PNG replay по закреплённому историческому SHA256; файл по mutable-пути
A v001 позднее изменился и больше не является равным референсом. Этот replay
не проверяет текущую модель. Новый output обязателен.
Сценовые MAXScript не опубликованы как проверенный новый адаптер: у исторических
скриптов зашит путь сцены, перенос меняет условия защиты, а native fileIn нового
параметризованного кода не выполнен. Следующий шаг — выделить общий remap по
manifest, проверить guard/rollback на копии MAX, повторно открыть и сверить
геометрию, UV/ID; затем FBX roundtrip/Checker. Этот перенос остаётся открытым.

Локальные входы: `jobs/A-MAIN-ATLAS/outputs/v001/uv_before.csv`,
`face_uv_before.csv`, `jobs/GLB-NPM/outputs/source-live-v001/textures`.
Карта `A_Main_1001_2048_RGBA.png` и модель в ignored outputs отсутствуют в Git.
Пакет не воспроизводит неизвестные ручные изменения v005 и не меняет нормы YAML/PDF.
