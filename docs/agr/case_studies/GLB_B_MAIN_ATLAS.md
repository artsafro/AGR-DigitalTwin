# ГЛБ B_Main — ID/UV и исправленное белое стекло

Источник: чат «Спланировать моделирование башенок Н»,
`01a0ebe4-71b4-70c3-90dc-03fa3cc956ff`, 01.10.2026.
Пользователь оценил работу над B_Main как успех. Приняты подход и результат
в текущей сцене; полный Checker, экспортный readback и сдача ОКС не приняты.

## Задача и исправления

3ds Max 2024, B_Main: 12156 Editable Poly faces, UV1, 11 используемых ID.
Источник отделки — MAX/SKP и захваченные SketchUp-текстуры. После проверки
общих UV-вершин между ID не обнаружено; ID перенумерованы 1–11,
UV перенесены в области одного RGBA PNG 2048²/UDIM1001.
Бетон вырезан без стыка из внутреннего участка карты; жёлтый металл и колонны
взяты из источника. Окна и AC-перфорация восстановлены визуально, а не извлечены
как исходные карты. Перфорация только фронтальных AC-чартов находится в alpha.
Первое стекло серо-голубое: пользователь потребовал белое. Генератор исправлен,
старый v001 сохранён; новая белая карта B_Main — v002. Это предпочтение данного
кейса; утверждённые нормы в этом PR не изменяются.

## Проверки

Исторический MAX v001 повторно открыт: 7 исходных объектов сохранены,
атлас назначен только B_Main, счёт граней по новым ID совпал, задействованные
UV примерно 0.0039–0.9961. SHA256 MAX:
`CF64031A681EEF1BE46919238BC1BBC00DD9B7262BC791E0327E5C63F9116835`.
Рендер не завершён из-за отсутствующих старых карт других объектов.
Alpha после FBX, полный Checker и визуальный QA модели не проверены.
Исторический readback v001 не доказывает все свойства поздней сцены с v002.
