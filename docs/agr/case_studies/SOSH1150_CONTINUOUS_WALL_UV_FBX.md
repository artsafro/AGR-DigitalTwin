## Оценка пользователя

- 01.10.2026: «спасибо, молодец, успех» после выдачи FBX и ZIP с diffuse.
- Принят результат этапа UV/рисунка стен v006 и подготовленный FBX-пакет.
  Область выводится из последовательности запросов; пользователь не сообщал

- Версии v002–v005 остаются диагностическими, их не считать принятыми.

## Задача и входы

- Открытые стены Blender4.4, Object1746168144,8755граней; единицы1м.
  Исходная плотность около585px/м. Снимок outputs/source_v001.blend сохранён.
- Пользователь просил один UDIM1001, повторяемые UV с наложениями и
  непрерывные наклонные белые линии; исходный diffuse4096² приложен напрямую.
- Сначала ориентир1500px/м. Затем: горизонтально отразить diffuse и укрупнить
  плитки/интервалы приблизительно втрое. Итоговое прямое разрешение — диапазон
  550–1500px/м, можно согласовать UV и сгенерировать соответствующую карту.
- Отдельный запрос: FBX с UV и картой для самостоятельного импорта в Max.
  После запрета пользователя Computer Use не применялся.

## Что сработало и что пришлось исправить

- Общий вертикальный масштаб по Z, горизонтальные charts по стенам;
  согласование фазы на углах, разрезы по периодам рисунка и UV-наложения.
  Сохранены исходные поверхности/проёмы и source_face provenance.
- Фиксированные1500 оставляли14конфликтных рёбер четырёх замыканий и
  нулевой padding. Разрешённый диапазон позволил согласовать45charts/52corner
  constraints с небольшой местной горизонтальной подстройкой.
- v002/v003: почти совпавшие точки разрезов приводили к некорректным граням
  или потере площади. Исправлено согласованием edge splits, дедупликацией
  последовательных точек и сверкой площади по source_face.
- v005: повторная проекция почти плоских вертикальных triangles меняла
  фазу на35endpoint samples. v006 сохраняет общий chart mapping при нарезке.
- ImageGen-проба не сохранила нужное число линий/доказанную периодичность.
  Финал изготовлен из существующего редактируемого процедурного источника F1.
  Это отдельная карта, не pixel-exact зеркало исходного PNG.
- Размер рисунка увеличен≈2.5–2.9раза относительно UV1500, не строго3.0.

## Воспроизведение

- База d7ecdfd; скрипты локальные, без коммита, каталог
  `jobs/UV-CONTINUOUS/scripts/`. Существенные:
  `plan.py`, `closure_final.py`, `final_plan.py`, `build_v005.py`,
  `build_final_texture.py`, `apply_v006.py`, `readback_v006.py`,
  `render_v006.py`, `export_max_v006.py`, `package_max_v006.py`.
- Точный период **4056px**, карта4096², padding20px с каждой стороны. База600px/м;
  горизонтальные масштабы0.843925–1.050187, вертикальный масштаб600.
  UV = padding/4096 + (metric_coordinate ×600 mod4056)/4096.
- Угол согласуется по одному горизонтальному параметру; solver допускает
  остаток меньше0.01px на исходных graph constraints. Это местная деформация,
  не универсальная изометричная развёртка произвольного фасада.
- Карта:3колонки/8рядов кассет,8горизонталей/2диагонали; отражение направления,
  периодический wrap-padding, проверка двух соседних texels на каждом краю
  для непрерывности bilinear sampling.
- Принятые версии/хеши: [ACCEPTED_V006.json](../../jobs/UV-CONTINUOUS/ACCEPTED_V006.json).
  Выходы в `jobs/UV-CONTINUOUS/outputs/`: `walls_UV550-1500_FlipH_v006.blend`,
  карта `T_Template_Address_001_Diffuse_FlipH_v005.1001.png`,
  `FBX_For_Max_v006/Walls_FlipH_v006.fbx`, `Walls_FlipH_v006_FBX_For_Max.zip`.
- Запуск DCC: Blender4.4 `--background --factory-startup --disable-autoexec
  --python-exit-code 1 --python <script>`. Live-операции — существующий
  `jobs/MASHI-LP/scripts/live_call.py`, порт9876, только после проверки сцены.
- Export: selection-only mesh, без triangulate/modifiers/animation,
  Zup, FBX_SCALE_UNITS, path_mode=COPY, embed_textures=true.
  FBX-материал отдельно упрощён до diffuse; живая сцена не менялась.
- Модели/карты/промежуточные JSON локальные; наличие их в Git не подтверждено.
  Для повторения нужен собственный новый output, исходная геометрия и конфиг;
  scripts/final_plan.py нельзя запускать повторно вслепую поверх изменённого plan.

## Переиспользование

- Связан с [Обр22](OBR22_ACCEPTED_WORKFLOW.md): материаловые UV-наложения,
  сохранение физического масштаба и проверка сохранённого файла. Отличие —
  наклонный декоративный рисунок и система фаз на замыканиях фасадов.
- Уровень: один принятый кейс этой операции; второй проект не проверен.
- Решение: оставить воспроизводимым сценарием. Кандидат на параметризованный
  адаптер «phase-aligned shared UV + periodic texture + FBX readback»;
  универсальный Skill/автосборка не объявлены.
- Параметры следующего испытания: геометрия, finish IDs, физический период,
  TD диапазон, padding, mirror flag, допустимая деформация. Проверять фазу
  по фактическим общим рёбрам, плотность, площадь и FBX Content bytes.
- Следующий шаг при новом запросе: второй проект/другой контур и native Max
  readback; принятый v006 и текущую Max-сцену не перезаписывать.
