## Задача и входы

- На каждой рамке трёх этажей сделать простой box light по существующему образцу:
  inset верхней внутренней поверхности, оболочка вверх, без скрытой верхней
  крышки, с небольшим опусканием. Скриншот и MaxScript пользователя — контекст
  исполнения, фактическая геометрия образца — источник размеров.
- Blender 4.4.0, единицы 1 м; live PID 68996 подтверждён. Два исходных меша:
  `frames` (3118 вершин/2352 грани) и `box_light` (8 вершин/5 квадов).
- Исходная сцена скопирована в `outputs/box_light_source_v001.blend` в каталоге
  задания. Исходные рамки и образец сохранены без изменения.
- Отступ 114,6 мм; высота 94,593 мм; опускание 21,103 мм измерены по образцу.
  Значение Shell 0,036 из истории Max не подменяет измеренную высоту корпуса.

## Что сработало и что пришлось исправить

- Разделение меша на связанные компоненты, затем отбор направленных вниз
  поверхностей в верхней половине каждого контура. Учтены наклонные и ломаные
  перекладины. 149 mesh-компонентов соответствуют 148 контурам рамок:
  одна рамка имеет раздельные внутренний и внешний контуры.
- Образец соответствует исходной грани 1081; эта грань исключена из генерации,
  чтобы сохранить образец без дублирования. Получено 247 новых секций,
  1235 квадов; вместе с образцом — 248 секций.
- Первый порог normal.z < -0,99 пропускал более крутые наклонные участки;
  для этого источника использован порог -0,1 и проверка положения в компоненте.
- Аналитическое пересечение линий inset не подошло для неплоских исходных
  четырёхугольников. Использован native `bmesh.ops.inset_region`.
- v001 унаследовал 48 неплоских оснований. v002 выравнивает новые основания
  в плоскость, дополнительно опуская их на величину до 65,85 мм. У одного
  участка 1574 высота корпуса увеличена до 97,055 мм для врезки минимум 10 мм.
  Рамки при этом не выравнивались и не перестраивались.
- При append нельзя сохранять файл поверх использованной библиотеки Blender:
  ошибка `Cannot overwrite used library`. Live-результат сохранён под отдельным
  именем `frames_box_lights_live_v002.blend`; исходная библиотека сохранена.
- У образца нет материала: shader и реальные источники света не добавлялись.

  `jobs/WINDOW-FRAMES/outputs/box_lights_v002_qa.json`.

- Уровень доказательств: один кейс, один источник; второе здание не проверено.
- Оставить сценарием. Кандидат для будущего адаптера: измерение образца,
  поиск внутреннего верхнего контура, native inset, открытая оболочка,
  проверка планарности и сохранённого результата.

  требуют проверки; критерий по верхней половине не универсален.
