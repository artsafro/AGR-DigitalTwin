## Инстансы и материалы

Созданы три общих mesh-источника окон: 12 лоджийных, 30 двухстворчатых, 3 одностворчатых.
Матрицы экземпляров сохраняют наружные размеры рам, врезку и индивидуальную посадку.
Внутренние детали нормализованы по представителю типа: максимальное отличие 0.534 мм.
Типы, Revit ID и измерение отличия записаны в uv-manifest.json и Blender-файлах.
Проверка пересечений после раскрытия инстансов пройдена.

Расположение отделки предложено по наружным типам Revit (Бел/Син/Кирп), сопоставленным
с легендой выбранного PDF. Это не извлечение всех Face.MaterialId из Revit.
23 грани смешанных торцов/неоднозначных откосов помечены finish_id=0, ярко-розовым.
Для них нужна точная пространственная маска границ отделки по фасадам 14–15.

finish_id — семантический атрибут грани, сохраняющий номер легенды PDF.
Material ID слота мастера (с единицы): 1 → UNRESOLVED, 2 → PDF 2, 3 → PDF 4,
4 → PDF 5, 5 → PDF 6, 6 → PDF 7, 7 → панель/G01 (внутренний finish_id 90, не номер PDF).
В текстурных вариантах один OPAQUE-слот обслуживает весь атлас или все 19 UDIM;
панели окон используют отдельный нетекстурированный материал.
Material ID и UDIM — разные сущности; соответствия один к одному нет.

## UV и разрешённая нарезка ВПМ

НПМ: один PNG-атлас 2048², padding 8 px, один UV-канал. Мастер имеет ту же UV-развёртку
и семь слотов для просмотра ID. Мастер и НПМ сохраняют принятую сетку: 2603 квада.

ВПМ: 19 плиток 1001–1019, PNG 4096², padding 32 px, один UV-канал.
Пользователь разрешил разрезать геометрию под тексель Connect-разрезами на логичные квады
меньше 4 × 4 м. Это дополнительное правило пользователя, не цитата из PDF.
Применено согласованное деление противоположных рёбер с распространением через соседние
грани: 2633 квада, всего +30. Максимальная сторона 3.4753 м.
Плотность с учётом матриц экземпляров: 513.98–514.09 px/м, исключений нет.
Сравнение 827 групп поверхностей до/после разрезов подтвердило сохранение формы.

Повторяющиеся окна разделяют UV намеренно. ВПМ-панели имеют UV в 1001 и отдельный
нетекстурированный материал; их разрешённые пересечения UV не смешаны с непрозрачными островами.
Проверены реальные UV после повторного открытия файлов, padding, отсутствие зеркальных
островов, случайных overlaps и совпадение пикселей атласа с назначенными ID.
