# НПМ v012: масштаб по принятой ВПМ, без требования плотности Ground

Пользователь принял ВПМ v011. Её `.blend` и4 карты не изменены, хеши проверены.
Указал: плотность НПМ относится к Ground, для архитектуры ОКС важен одинаковый
размер материала с ВПМ. Визуально проверена исходная PDF-страница10, раздел6,
пункты1–2: требование относится к рельефу, ОКС исключён. YAML уже был правильным.
Ошибка предыдущего этапа — применение Ground-проверки к BODY НПМ и представление
её прохождения как критерия приёмки. Старая запись сохранена как история,
для будущего запуска `check_shared_uv_agr.py` теперь выдаёт НПМ-ОКС not_applicable.
Основной валидатор `src/dt_ai/validate/bundle.py` не ограничивает плотность НПМ;
его проверки плотности относятся к vpm_uv, менять их не потребовалось.
