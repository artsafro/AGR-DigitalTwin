Соответствие:1001 — тёмно-серая/finish4;1002 — светло-серая/finish2;
1003 — белая/finish3;1004 — кирпич/finish5. У finish3 нет подтверждённых граней
в текущем этаже: карта включена, но не присвоена вместо неизвестной отделки.
Неопределённые ID0 сохраняются розовыми:23 грани НПМ,38 после прежних разрезов ВПМ.

Совместимые UV накладываются в области одного материала. Направление и масштаб
не меняются при укладке; сдвиги кратны периоду кладки/плитки с общей фазой.
Фазы выбираются по всему материалу так, чтобы длинные грани вошли с padding.
Горизонтальные длинные торцы ориентированы вдоль широкой стороны области атласа.
Дополнительные геометрические разрезы в этой итерации не понадобились.

Карты **пересобраны**, а не просто растянуты целиком: швы по заданным размерам,
внутри элементов — интерполяция образцов поверхности из исходных изображений.
Кирпич250×65мм/шов10мм, плитка600×1200мм/шов5мм. Новая фактура высокого разрешения
не восстановлена из маленьких образцов: плавность интерполяции не является
настоящей дополнительной детализацией. Проверена плотность UV, не фотографическое качество.
Точная исходная картинка/толщина запечённых старых швов при пересборке не сохраняется.
Структура четырёх полос НПМ сохранена; нижняя часть исходного атласа от строки1789
(образцы окон/подписи/цвета) побайтово совпадает после чтения PNG. Модель окон
остаётся геометрической: чужие силуэты окон из примера ей не назначались.

Рамы НПМ используют существующий одноцветный образец RAL7024 из атласа;
рамам ВПМ оставлен отдельный плоский материал без пятого UDIM. Стекло отдельно
по материалу, пока в тех же типовых mesh. Это рабочий вариант, не финальный состав экспорта.
