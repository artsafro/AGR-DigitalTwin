# Инвентаризация инструментов Digital Twin AI

Снимок 26.09.2026 с дополнениями GeoAGR13.63 и двумя папками скриптов. **73 инструмента/семейства/цепочки, 162 проверенных пути,
21 группа выбранных точных дубликатов.** Это каталог применимости, а не подсчёт
всех установленных DLL. Исходные профили требований и приложения не изменялись.

Открыть [каталог с поиском](catalog.html), [CSV для Excel](catalog.csv) или
[машиночитаемый реестр](catalog.json). Каждая запись содержит пути, среду/версию,
назначение, зависимости, исходный код, свидетельства активности, решение и DT-ID.
Предложенные решения по переиспользованию — инженерный план, не ТЗ заказчика.

Последнее дополнение: [zavod и Плагины 3dMax](ZAVOD_AND_MAX_PLUGINS_REVIEW.md) —
1398 metadata records,48 MZP,40 модулей xView совпали с установленными. Добавлены
13 конкретных семейств/операций; выявлены ограничения Collizii/UDIM Viewer,
опасные побочные эффекты очистки и готовые основы census/asset/UV adapters.
Дополнительные группы дубликатов содержатся в `folder-followup-evidence.json`;
21 группа выше относится к исходному `duplicates.json`.

## Главные результаты

1. **GeoAGR уже подключён к рабочему Max.** Кнопка есть в текущем workspace
   `artsafro__usersave__.cuix` и Octopus. Установленные подсказки охватывают НПМ,
   ВПМ, UDIM, UCX, GeoJSON, координаты и экспорт. MSE раскрыт и оказался загрузчиком
   EXE/clipboard. В новой поставке13.63 найден AutoIt SCRIPT и API трёх DLL;
   два отдельных CLI испытаны на synthetic OBJ/PNG. Основной EXE не декомпилирован,
   актуальность внутренних правил не установлена. Версии EXE нет в
   Windows VersionInfo. Первое действие — тест на отдельной синтетической сцене,
   не переписывание всей цепочки. Поставка13.63 на Desktop не установлена в Max.
   [Находки и ограничения CLI](GEOAGR_13_63_REVIEW.md): UCX checker пропускает
   вложенность, а uvdilate теряет alpha — обвязка должна учитывать это явно.
2. **SINTEZ AGR Checker 1.6.1 включён в сохранённых prefs Blender4.4.** Есть исходный
   Python проверки ZIP/FBX/UV/UDIM/UCX/GeoJSON, отчётов, исправлений и подключения
   ВПМ-карт. В профиле5.0 лежит1.5.0. Надо сначала сопоставить его findings с
   PDF/нашими V-кодами. Установленный проверяющий инструмент не является нормой.
3. **Octopus хранит самостоятельный код.** Кнопка A101LP содержит63058 символов
   команд для Main/Ground/GroundEl/Flora и материалов; её нет смысла искать только
   как отдельный `.ms`. Кнопки UCX_Concave/UVTools/GeoAGR тоже связаны в меню.
4. **BMAX подключён с обеих сторон**, но текущий Max-side preset использует
   FBX2012. Отдельно штатный Max FBX сейчас2014, triangulate=true, embed=false.
   Это нельзя использовать как общий preset сдачи НПМ. Адаптер обязан задавать
   профиль явно и проверять результат после повторного импорта.
5. **Есть готовые инженерные цепочки**, а не только плагины: фасадный atlas UV
   Blender→Max; DWG→AcDbTable/HATCH→именованные DWG→Max; Revit Face loops→Python
   topology→Blender; UCX batch repair с coverage/gap/readback. Свежие файлы
   `.Facades_Modelling` содержат результаты, отсутствовавшие в старых заметках.

## Что именно проверено

- 3ds Max2024 **26.2.5.192**, два процесса. От одного действующего bridge получены
  read-only ответы, пути, текущий CUI, список загруженных DLL и FBX-параметры.
  Renderer=Corona; Forest9.2.4/RailClone7.0.8/V-Ray7.00.04/tyFlow доступны;
  Octopus3.15/SiNi2.0/Datasmith и другие DLL загружены. Проверка конкретной команды
  плагина не выполнялась. Нельзя переносить состояние одного Max-процесса на оба.
- 3ds Max2026 **28.3.0.30732** установлен; его пакеты/профиль осмотрены статически.
- Blender4.4 установлен, **4.4.0** проверен предыдущим этапом проекта. Сейчас
  процесса нет. Список включённых аддонов получен из DNA `bAddon` userpref.blend,
  без запуска Blender и стороннего `register()`. Включены SINTEZ, BMAX,
  Quad Remesher и штатные FBX/glTF. CheckToolBox1.4/1.5 и RizomUV Ultimate лежат
  на диске, но не включены в этих prefs. У CheckToolBox1.5 есть отдельные batch
  runners и результаты: «не включён в UI» не означает «не применяется».
- Профиль Blender5.0 найден; его новый binary header не разобран. Включение
  аддонов5.0 и executable не подтверждены; ничего не запускалось для догадки.
- AutoCAD2025 **R25.0.72.0.0** установлен, процесса нет. Проверены support paths,
  стандартные/пользовательские CUIX как архивы данных, DWT, LISP и MCP-registration.
  В проверенных CUIX не найдены текстовые ссылки на загрузку внешних LSP/FAS/VLX.
  Это не полная проверка всех runtime-путей APPLOAD. COM в этом этапе не проверен.
- Revit2025.2 **25.2.0.38**, build20240715_1515. Процесса нет. Два addin manifest
  и DLL присутствуют: named-pipe Cursor Bridge и HTTP MCP. Текущий API handshake
  отсутствует. Отдельный ContourProbe существует как исходник/артефакты исследования,
  но его регистрация в текущем стандартном Addins2025 не обнаружена.
- Dynamo/Generative Design поставляются с Revit. Пользовательская Dynamo/pyRevit
  цепочка в охваченных путях не обнаружена. Штатные образцы не считаются рабочим
  процессом команды. Полноценный поиск вне охваченных roots остаётся возможным.

## Охват и границы

Просмотрены56 корней двух проходов (часть пересекается),70623 уникальных метаданных
файлов подходящих расширений: Desktop, Documents, рабочие проекты пользователя,
Cursor/Codex, Max2024/2026 целиком с исключениями, плагины ProgramData/AppData,
профили Blender/CAD/Revit, публичные пользовательские папки и B:/Backup.
Ошибок обхода в разрешённых проходах нет. Подробности — [coverage.json](coverage.json).

Командные кандидаты найдены в `Desktop/!3D viz/Плагины 3dMax/Andrew_scripts`,
`Hotkeys_Workspaces_Scripts`, `Desktop/zavod`, `INTERACTIVE_TOUR`,
`Documents/ChatGPT/Blender`, `.window_facades`, `.Facades_Modelling`.
Это рабочие каталоги на этой машине; совместный доступ другим людям не доказан.
На B: резервные копии. На D: проверен верхний уровень (ассеты/ПО), без полного
обхода моделей. Подключённых UNC-дисков не выявлено. Dropbox/OneDrive/Yandex
проверены на верхнем уровне; содержательной общей библиотеки скриптов там не видно.
Сетевые ресурсы, отсутствующие на машине или скрытые в cloud placeholders, не искались
перебором адресов. Пользовательский startup.blend/maxstart.max не найден в охвате;
RPS и Moscow_boundaries_MSK.max найдены, но не открывались как рабочие сцены.

Переписки и браузерные базы исключены из анализа. Лицензионные и авторизационные
данные в результат не включены. Полные настройки не скопированы; экспортированы только выбранные
свидетельства DCC-подключения. Исходники и бинарники инструментов не копировались,
не перемещались. В начальном проходе выполнялись собственный сборщик
метаданных и read-only запросы в уже работающий Max. В дополнении MSE запускался
reviewed decoder, в дополнении GeoAGR13.63 — два CLI на собственных временных
фикстурах и анализатор metadata. Главный EXE, DLL-методы и рабочие проекты
не запускались в этом дополнении. Обычный доступ к внешним
папкам был ограничен sandbox; разрешённый read-only проход завершился успешно.

## Активность и дубликаты

Статусы разделяют текущий runtime, настройку, сохранённые результаты и только
наличие файла. Состояние «постоянно использует команда» требует подтверждения
человека. MRU/mtime и наличие кнопки по отдельности этого не доказывают.
Слово «заменить» в реестре — будущая унификация, не удаление оригинала сейчас.

[duplicates.json](duplicates.json) содержит21 выбранную группу SHA256:
BMAX2024/2026/Backup, UDIM-MultiSub, FloraAtlas MCR, ConcaveFixer,
WindowDummies, CheckToolBox и его runners. Повторные deploy-копии в разных
приложениях бывают необходимы. Разные SHA у atlas_builder24/portable, разные
версии SINTEZ/CheckToolBox и два MCP checkout — это варианты, не точные дубликаты.
