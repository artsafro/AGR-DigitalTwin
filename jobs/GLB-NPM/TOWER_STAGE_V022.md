## Воспроизведение и доказательства
- Исходник: source-live-v001, floor-instances.json содержит16измеренных матриц,
  начиная с B на12.7м, заканчивая A на62.2м; типовая часть до65.5м.
  top-source.json: unique source206495,definition169633, верх74.299878м.
- inspect_exterior_ab.py, build_k1_typical.py:96задних граней стоек и97caps
  на каждый тип A/B удалены; исходные горизонтальные поверхности далее
  восстановлены только в наружных областях. Геометрия стоек без новых bevel-полос.
- clip_k1_coplanar_joints.py, finish_k1_typical.py:16граней пояса разделены
  в общей плоскости,117согласующих разрезов; UV сохранены. Врезаемые оболочки
  не превращались в рёбра с3+гранями.
- start_k1_top.py: отдельная рабочая коллекция уникального верха, узлы windows/AC
  заменены planes. Верх ещё не является готовым НПМ и не включён в QA типовой части.
- clean_k1_inside.py, trim_sill_interiors.py, trim_sills_to_exterior.py,
  apply_exterior_sills.py, prepare_exterior_ledges.py, finish_exterior_shell.py,
  prepare_misc_exterior.py, finalize_k1_stage.py: очистка внутренней оболочки.
- Удаление всего нижнего полигона перекрытия было ошибкой: наружные выступы
  требуют подшивки. Для их восстановления использованы реальные сечения BODY+окон.
  Constrained Delaunay сохраняет площадь сложных контуров; обычная триангуляция
  с проверкой только центроида оставляла пропуски и поэтому отклонена.
- При финальной сборке скрытые10мм полосы окон сверху/снизу обрезаны по границе
  наружной оболочки (высоты1.0–3.3м внутри этажа), чтобы изнутри не видеть их лицом.
  Середина глубины и боковой заход10мм сохранены. Это финальное удаление скрытых
  частей, а не повторное утапливание окна за проём.
- Узкие уровни отливов разведены5.1мм вместо ровно5мм: запас0.1мм против float
  округления при переносе на высоту. Изменение не касается принятой формы фасада.
- attach_k1_stage.py: один mesh типовой части с npm_part_id и общим Atlas_UV;
  дополнительный FinishUV сохранён. Вариантыv017/v018 с массовым добавлением
  граничных вершин отклонены: микроскопические грани ухудшили проверку изнутри.
- verify_k1_delivery_stage.py, merge_reveal_seams.py, finish_k1_seams_and_uv.py:
  удалены3вырожденные грани;33микроскопических наложения швов откосов объединены
  в плоскости. Для n-gon с коллинеарным началом checker теперь берёт нормаль по
  всему полигону;8синтетических тестов, включая разделённое ребро, проходят.
- restore_k1_ledge_uv.py:7828наружных граней подшивок получили UV исходных A/B.
  v022-uv-readback.json подтверждает неизменную геометрию после UV-переноса.
- v021-clearance.json:27723фейса,0близких параллельных пар при5мм.

  Это выборочная геометрическая проверка, не доказательство всех возможных ракурсов.
