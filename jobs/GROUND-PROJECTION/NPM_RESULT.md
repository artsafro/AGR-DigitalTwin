## Геометрия и ограничения
32392 квада,33103 вершины; лимит50000 соблюдён для основного quad-FBX.
Триангулированная версия содержит64784треугольника — это отдельный, явно больший счётчик.
Масштаб исправлен по подтверждению пользователя:116.447×163.833м.
Базовое деление ориентировано на3м, на перепадах и контурах оно мельче.
Это не равномерная сетка3×3м: сложные границы покрытий требуют дополнительных резов;
средняя длина ребра, взвешенная по площади, около1.42м.
Высоты берутся со сглаженного поля: медиана2.5м, квантование25см, Gaussian sigma1.6м.
Мелкие ступени10–20см подавлены, крупные перепады передаются плавными уклонами.
За исходным рельефом использовано продолжение ближайшего уклона перед сглаживанием.
Слишком крутые микрополосы исправлены изменением только Z; наибольшая локальная поправка11.9см.
Точного прилегания к исходному рельефу намеренно нет. Максимальный наклон грани56.42°.

Контуры18материалов сохранены с численной решёткой1мм: отклонение выборок
границ после FBX≤0.715мм, выборок дальше2мм нет. Полный симметричный аудит в contour_qa.json.
Исходные перекрытия разных ID сохранены по прямому указанию пользователя.
316non-manifold рёбер имеют несколько разных ID, однородных по материалу таких рёбер0.
На перекрытиях возможен z-fighting; это не устранение исходных пересечений.

## Проверки сохранённых файлов
Повторный импорт обоих FBX:18слотов, имена и material ID совпадают,
включая сырой LayerElementMaterial. PNG внутри FBX проверен побайтно.
Нет точных дублей вершин, дублей граней, граней нулевой площади,
перекрученных квадов, loose vertices или ngons. Исходные перекрытия — отдельное исключение выше.
Blend повторно открыт; фактическая quad-сетка проверена. Превью просмотрены.

UV: один канал, тайл0–1, намеренное повторное использование областей по отделке.
Плотность quad-FBX19.91–20.24px/м; TRI19.52–20.31px/м. Все грани проверены,
ниже10/выше40 —0. Использовано точное тело расчёта установленного AGR Checker2.6.1
(CheckUtils._calculate_td), хеши источника и snapshot сохранены рядом.
Это точечная проверка плотности, не полный запуск/приёмка AGR Checker.
Атлас содержит только исходные цвета; рисунки реальных покрытий не выдумывались.

Нативный импорт в3ds Max не выполнялся. FBX7.4 Binary, метры, normals и порядок
материалов проверены обратным импортом Blender. В Max импортировать материалы и normals;
при возникновении переупорядочивания сверяться с material_ids.json.
Полная нормативная сдача НПМ и визуальная приёмка пользователем остаются открытыми.
passed=true для полной сдачи не заявляется.
