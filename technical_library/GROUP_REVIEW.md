# Все группы: операции и проверка

Проверены маршруты всех 15 групп, 601 исходных путей. Это реестр происхождения и решений, не 601 исполняемый файл в GitHub.
11 Workbench-файлов учтены по прошлому inventory без повторного чтения: PR18 отложен. 29 исключённых сторонних/неочищенных источников вне области.
Не каждый исторический построитель запускается или переносится. Общая диагностика протестирована на сохранённых файлах, успешные операции компактно переиспользуются, эксперименты остаются локально.

Подробные SHA/пути: [SOURCE_COVERAGE.jsonl](SOURCE_COVERAGE.jsonl); точные кандидаты дублей: [GROUP_REVIEW.json](GROUP_REVIEW.json). Совпадение функций не доказывает переносимость.

## Как выбрать код

Сначала пакет операции → его README и QA → данные объекта → новый output → readback. Версии v001/v002 не копировать как новые инструменты.
