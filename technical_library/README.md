# Техническая библиотека AGR

- [RunRecord inspector](../docs/organization/local-orchestration/RUN_EVIDENCE.md): переиспользует существующий ledger/AdapterReport, проверяет сохранённые файлы перед продолжением; native/manual gates отдельно.


- [ГЛБ A/B: атлас по захваченным UV](glb_atlas/README.md): один Python-генератор
  и hash-bound конфигурация двух корпусов; строгие replays совпали с закреплёнными
  SHA256, текущий B v002 совпал побайтно, а mutable A v001 позднее изменился. Native
  сценовый remap остаётся открытым; текущая A v005 не наследует QA прежнего v004.


Библиотека хранит компактные рабочие пакеты по операциям, а не каждый временный
скрипт из чата. Перед задачей выбирайте операцию и прочитайте её область проверки.
Новый объект получает конфигурацию/данные; новый Python-файл нужен только для
новой ответственности, которую нельзя добавить в существующий пакет.

[Все 15 групп и их решения](GROUP_REVIEW.md). Реестр601 путей содержит только
метаданные; 11 Workbench-путей отложены, прочие исходники прочитаны/классифицированы.
Пять групп одинаковых файлов и57 функций — точные кандидаты, не автоматическая приёмка.

## Исполняемые пакеты

- [Общий mesh inventory](mesh_audit/README.md): одна диагностика и Blender-адаптер,
  9 фактических saved-file readbacks; без изменения approved источников.
- [Карты материалов](texture_tiles/README.md): один CLI, данные КПП отдельно,
  reuse существующего метрического raster; 11 PNG побайтно совпали и ZIP прочитан.
- [Атлас окон/дверей](window_atlas/README.md): одна реализация отрисовки,
  отдельный JSON параметров здания, CLI build/readback. Геометрия больше не
  зависит от номера ID. PNG совпал с принятым v8 по каждому пикселю, UV CSV
  сохранил mappings и размеры. Native model UV/Max этим тестом не подтверждены.

- [UV стен v006](UV_V006.md): четыре этапа `inventory → solve → build → verify`,
  один общий модуль состояния/запуска. Десять исторических операций объединены;
  прежние скрипты в этот пакет не копируются. Один проверенный объект СОШ1150.
- [Box lights, PR #25](https://github.com/artsafro/AGR_Project/pull/25): четыре
  этапа инспекции/анализа/построения/QA, с README и native Blender replay.
  Пакет слит в `main` коммитом `946acad`.
- Connect, Exterior, Shell — существующие модули `src/dt_ai/`;
  рисунок фасадов — `tools/facades_texture_pattern.py` с адаптерами и тестами в main. Переиспользовать их;
  исторические прототипы не должны создавать вторую реализацию той же операции.
- [Workbench, PR #18](https://github.com/artsafro/AGR_Project/pull/18) — собственный
  Max-пакет уже сохранён отдельно; его ревью/QA отложены пользователем.

## Правило пополнения

1. Из этапов успешной задачи выделить ответственности, входы/выходы и проверки.
2. Найти существующую реализацию и определить, что является новым алгоритмом,
   параметром конкретного объекта или временной диагностикой.
3. Обновить существующий модуль либо создать небольшой пакет с понятными этапами.
   Общую логику вынести в функции; параметры/ID/пути оставить в конфигурации.
4. Сравнить результаты исходного маршрута и рефакторинга на тех же входах.
   Добавить README, небольшой QA-отчёт, связь с кейсом и ограничения.
5. Черновые версии и дубли остаются локально. Ошибку сохранять как вывод с
   контрпримером/проверкой, а не десятки копий неудачного кода.

Четыре этапа — модель этого UV-кейса, не обязательное число для всех задач.
Главный критерий — одна реализация операции и воспроизводимый результат.
Нельзя объявлять общий Skill по одному объекту; переносимость проверяется отдельно.

[Ретроспективный аудит и группировка](../docs/history/organization/TECHNICAL_MIGRATION_AUDIT.md).
Большие outputs и модели не опубликованы; hash-манифест не является бэкапом.


## Существующие точки входа

- Read-only гигиена: `tools/project_hygiene.py`; цикл — [GitHub workflow](../docs/organization/GITHUB_CODEX_WORKFLOW.md).
- Connect: `tools/quad_connect.py`, `src/dt_ai/geometry/connect.py`; Exterior: `tools/run_exterior.py`; Shell: `tools/run_body_shell.py`. Читать AdapterReport и ограничения конкретного пакета.
- Фасадный рисунок: `tools/facades_texture_pattern.py`; геометрия/ID/UV и native roundtrip проверяются отдельно.
- Box lights: [job README](../jobs/WINDOW-FRAMES/README.md); UV/экспорт/Checker не следуют из принятия размещения.

## Пополнение библиотеки

Сохранять фактически использованный собственный код, зависимости, параметры и запуск, малые QA-отчёты, единицы и предпосылки математики, ограничения и отрицательные примеры. Код одного объекта остаётся сценарием кейса; общий адаптер требует проверки переноса. Outputs/полные чаты/секреты и промежуточные варианты остаются вне обычного Git.

Прежний [каталог операций](../docs/history/organization/SCRIPT_LIBRARY_BEFORE_CONSOLIDATION.md) сохранён как provenance; рабочий каталог теперь этот README.
