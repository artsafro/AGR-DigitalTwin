# UV стен СОШ1150 v006: четыре этапа

[Кейс и область приёмки](../docs/case_studies/SOSH1150_CONTINUOUS_WALL_UV_FBX.md).
Сохранённая логика десяти временных сценариев объединена в четыре модуля:
`uv_continuous/inventory.py`, `solve.py`, `build.py`, `verify.py`.
`common.py` содержит только общий контроль рабочей папки и запуск Blender.
[Происхождение операций](uv_continuous/REFACTOR_SOURCES.json) сохраняет SHA
исторических исходников без публикации их копий.

## Входы и четыре команды

Blender4.4 и Python с NumPy/Pillow. Исходная сцена `source_v001.blend`
(активный mesh8755 граней) и исходный diffuse4096². Это маршрут одного объекта,
не автоматический unwrap произвольного здания. Используйте новую папку output;
первый этап откажется перезаписывать существующую папку.

В PowerShell задайте свои пути:

```powershell
$blender = 'C:\\Program Files\\Blender Foundation\\Blender 4.4\\blender.exe'
$uvOutput = '<новая папка для результата>'
& $blender --background --factory-startup --disable-autoexec --python-exit-code 1 --python technical_library/uv_continuous/inventory.py -- --output $uvOutput --source-blend '<source_v001.blend>' --diffuse '<исходный diffuse.png>'
python technical_library/uv_continuous/solve.py --output $uvOutput
python technical_library/uv_continuous/build.py --output $uvOutput --blender $blender
python technical_library/uv_continuous/verify.py --output $uvOutput --blender $blender
```

1. **Inventory:** читает отдельную сцену, сохраняет snapshot, поверхности,
   материалы, UV и SHA входов. Оригиналы не меняет.
2. **Solve:** группирует стены и связывает фазу по общим рёбрам; замыкание циклов
   решает методом наименьших квадратов. Горизонтальный масштаб согласуется
   в разрешённом пользователем диапазоне. Период4056px, номинально600px/м.
3. **Build:** режет по периодам, согласует общие границы и формирует quads;
   создаёт отражённую diffuse4096² с полями20px и согласованными краями;
   применяет mesh/UV/карту в отдельном Blender и сохраняет новую сцену.
4. **Verify:** открывает сохранённый blend, проверяет UV/TD/фазу/поверхность,
   экспортирует и повторно импортирует FBX, проверяет Content PNG и привязку,
   читает фактические байты ZIP. Ошибка обязательной проверки останавливает этап.

`PIPELINE.json` разрешает этапы только в указанном порядке; повторный solve
после применения плана запрещён. Для другого объекта нужны отдельные входы,
параметры и испытание; утверждённый v006 не изменять.

## Что проверено

[Четырёхэтапный replay](evidence/UV_FOUR_STAGES_REPLAY.json) сравнивается с
[историческим десятишаговым replay](evidence/UV_CONTINUOUS_V006_REPLAY.json).
Все численные поля геометрического/UV readback должны совпасть. FBX и ZIP
проверяются повторным импортом/чтением, не только exit-кодами.

Эксплуатационная поправка: viewport настраивается только если есть
`bpy.context.screen`. Алгоритмы геометрии/UV не изменены.
Native Max import, полный AGR Checker и второй проект остаются непроверенными.
Повторный запуск не является новой визуальной приёмкой. Все Blend/FBX/PNG/ZIP
создаются локально, в Git входят код, описание и небольшие отчёты.
