# Атлас окон/дверей: единый генератор + данные объекта

`atlas.py` хранит алгоритм, `new_building_v8.json` — ID, размеры, створки,
фрамуги, RAL display RGB, привязки DOCX и подписи конкретного здания.
`cli.py` строит PNG/CSV и читает фактические файлы обратно. Временные генераторы
и старые версии в Git не копируются. Геометрические особенности больше не
определяются номером ID; изменение ID не меняет отрисовку профиля.

Python3.11+ и Pillow. Шрифты задаются явно (Arial/Arial Bold нужны для точного
повторения исторического результата; файлы шрифтов не распространяются).

```powershell
python technical_library/window_atlas/cli.py --config technical_library/window_atlas/new_building_v8.json --output <новая-папка> --fonts C:/Windows/Fonts
```

Для сравнения с историческими артефактами передать `--reference-png <PNG>` и
`--reference-manifest <CSV>`. CLI откажется перезаписывать существующий output.
README задаёт маршрут одного принятого кейса, не универсальную раскладку любого
атласа: размер полотна/раскладка/поля здесь сохранены от v8.

Для другого здания предоставлять отдельную проверенную конфигурацию; не
переносить чужие ID, размеры и цвета автоматически. Native UV/FBX/Max моделирования
в этой проверке не запускались. PNG/CSV создаются локально и в PR не включены.
