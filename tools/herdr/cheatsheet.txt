
  ЧТО СОЗДАВАТЬ
  Папка        новая часть проекта / новые файлы
  Pane         ещё одно окно рядом, та же ветка
  Tab / chat   новый разговор, та же задача и ветка
  Worktree     новая независимая задача или
               параллельная реализация (своя ветка + workspace)

  ПРАВИЛО
  Те же файлы и та же задача          -> новый chat / tab
  Нужна консоль / git / логи рядом    -> pane
  Отдельная задача, эксперимент,
  параллельная реализация             -> worktree / branch
  Разложить файлы по структуре        -> папка

  КЛАВИШИ  (Ctrl+B, затем)
  V   pane вправо          -   pane вниз
  C   новый tab            Shift+G  новый worktree
  W   сменить workspace    Q   отключиться (агенты работают)
  X   закрыть pane         Z   развернуть pane
  Shift+L  раскладка AGENT/TOOLS/LOGS/HUD
  Shift+V  ревью диффа     Shift+E  файлы + git
  A   передать сессию другому агенту    T   замечание к тексту
  F   просмотр файлов      I   вставить скриншот
  Shift+K  большие файлы ссылками вкл/выкл
  Shift+M  получить изменения: main <- GitHub, ветка <- main
  В русской раскладке те же клавиши (V = М, Shift+G = П ...)

  В worktree видны только закоммиченные файлы.
